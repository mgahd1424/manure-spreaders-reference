# ناثرات السماد العضوي — مرجع هندسي تفاعلي

مرجع رقمي تفاعلي يعمل في المتصفح، يغطي المبادئ الهندسية لناثرات السماد العضوي
وطرق عملها ومعايرتها.

🔗 **العرض المباشر:** [اضغط هنا للتجربة](https://mgahd1424.github.io/manure-spreaders-reference/)

---

## المحتويات

- **المبادئ الهندسية:** مسار نقل القدرة من عمود PTO عبر صندوق التروس وسلسلة
  الأرضية إلى الموزعات.
- **النمذجة الرياضية:** معادلات معدل التطبيق للناثرات الصلبة والسائلة، ومعايير
  انضغاط التربة وفقد النيتروجين بالتطاير.
- **تصنيف الأنواع:** خريطة ذهنية تفاعلية لستة أنواع من الناثرات.
- **مختبر المحاكاة:** حساب آني لمعدل التطبيق عند تغيير سرعة الجرار ومعدل التدفق
  وعرض النثر، مع عرض بصري لنمط التوزيع.
- **الصيانة الوقائية:** جدول صيانة دوري ومراجع علمية محكّمة.
